# VoiceNotes — Voice to Text

A privacy-first iOS app that turns voice into text. Record, transcribe in real time, or import an audio file — everything runs **on-device** with Apple's Speech framework. Nothing is uploaded, ever.

## Features
- 🎙️ Record with live transcription (pause / resume supported)
- 📂 Import audio files (m4a, mp3, wav…) and transcribe them
- 🌐 Chinese (zh-CN) and English (en-US) recognition, switchable
- 🗂️ History with full-text search, edit, copy, export as .txt, share
- 🔒 100% local processing — no servers, no accounts, no tracking

## Tech
- SwiftUI + AVFoundation + Speech framework (iOS 17+)
- On-device recognition preferred, long audio handled with segmented passes
- Project generated by XcodeGen, CI by GitHub Actions (macOS runners)

## Status
v1 in development. VoiceNotes is planned as a paid App Store release; the source is open under the MIT license — build it yourself for free, or support the project by buying the App Store version when it ships.
